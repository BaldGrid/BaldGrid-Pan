## ✨ 特点

- **资源浏览** – 文件夹式层级结构，直观展示 Android 刷机资源
- **实时搜索** – 按名称/描述快速定位资源
- **动态加载** – 支持 `loader` 节点，按需加载远程 JSON 数据
- **README 渲染** – 每个文件夹/文件可搭配 `.md` 说明，使用 `marked` 渲染
- **主题切换** – 浅色/深色模式，跟随系统或手动切换
- **液态玻璃效果** – 可开关的毛玻璃 UI（`backdrop-filter`）
- **内置音乐播放器** – 从 `data/music.json` 加载歌单，支持本地文件添加
- **作者展示** – 动态加载 `data/zuozhe.json`，显示作者卡片与链接
- **友情链接** – 外部跳转卡片

---

## 🚀 快速开始

1. 在服务器上部署所有文件
2. 确保文件结构完整
3. 用任意 HTTP 服务器打开 `index.html`（建议使用 Live Server）
4. 根据需要修改 JSON 数据文件
